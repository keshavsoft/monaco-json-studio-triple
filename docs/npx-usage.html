CLI (npx) Usage

Run monaco-json-studio-triple directly from the terminal without cloning.

Commands

npx monaco-json-studio-triple
npx monaco-json-studio-triple file-picker status
npx monaco-json-studio-triple select stats
npx monaco-json-studio-triple actions cursor

Generates ./monaco-triple-<header>-<footer> and automatically appends -1, -2, ... if the folder already exists.
