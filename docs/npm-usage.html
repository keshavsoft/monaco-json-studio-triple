Programmatic (npm) Usage

Install and import monaco-json-studio-triple inside Node.js ESM projects.

Install & Import

npm install monaco-json-studio-triple
import { createTripleStudio } from 'monaco-json-studio-triple';

createTripleStudio({ header: 'actions', footer: 'status' });

Exports createTripleStudio({ header, footer, panes, outputDir }) as both named and default export.
