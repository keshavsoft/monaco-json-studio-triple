Dependencies & Ecosystem

What monaco-json-studio-triple builds on and where it is used.

Direct Dependencies

  • handlebars (^4.7.10) — Compiles assets/v3/templates/document.hbs.
  • monaco-json-studio-base-header — Provides header .hbs rendering and dom-primitive-bindings actions.
  • monaco-json-studio-base-body — Provides the 3-pane triple workspace .hbs layout and Monaco runtime.
  • monaco-json-studio-base-footer — Provides footer .hbs rendering and cursor/stats updaters.

Used By
